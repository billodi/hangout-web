# Hangout Web Feature Roadmap

This plan turns the full feature set into safe, shippable phases.

## Phase 1 - Safety + Fast Discovery (Now)
- Add "Happening in next 2 hours" filter on map views.
- Improve mobile map reliability and sizing.
- Tighten report and block flows (quick access from profile/activity surfaces).
- Add "private visibility" controls for activities (public/friends-only/invite-only).

## Phase 2 - Coordination + Reliability
- RSVP reminders and event start nudges.
- Waitlist auto-promote when seats open.
- Polls and checklist inside activity details.
- Basic no-show tracking signal in reputation score.

## Phase 3 - Social Proof + Retention
- Post-event recap card with optional photos.
- Lightweight attendee feedback tags (friendly, on-time, organized).
- Host reliability stats (response rate, completion rate).
- Streaks and participation challenges.

## Phase 4 - Growth + Monetization
- Promoted activities with clear sponsored labeling.
- Premium host toolkit (advanced analytics, templates, audience insights).
- Optional deposits/paid ticket flow for high-demand activities.
- Referral rewards and city leaderboard boosts.

## Delivery Notes
- Ship behind feature flags where risk is medium/high.
- Prioritize mobile UX parity before adding premium surfaces.
- Add analytics events for every new funnel step.
